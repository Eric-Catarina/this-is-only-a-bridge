**🏆 1st Place Winner at GameJamPlus BH 25/26**

**This Is More Than a Bridge** is a hyper-casual action puzzle game designed for mobile devices. Inspired by the clever level-design logic of games like *"This is Only a Level"* and *"That Level Again"*, the game challenges players to cross a bridge in a legendary Fiat Uno.

The core experience revolves around a simple premise with a complex twist: every time the bridge is crossed, the stage reconfigures itself, introducing new physical laws, obstacles, or mechanical surprises.

## 🕹️ Gameplay & Features

* **Physics-Based Puzzles:** The bridge features a dynamic physics system where weight distribution and speed are key to survival.
* **Iterative Level Design:** Each "level" is a reconfiguration of the same space, forcing the player to adapt to ccontrols and environmental changes.
* **Hyper-Casual Mechanics:** Simple "pick-up-and-play" controls optimized for the mobile experience.
* **Iconic Brazilian Vibe:** Drive the ultimate performance machine — a Fiat Uno with a ladder.

## 🛠️ Technical Overview

* **Engine:** Built with Unity Engine.
* **Art Pipeline:** 3D assets modeled and optimized for mobile performance.
* **Design Philosophy:** Focused on emergent gameplay through physics interaction and minimalist puzzle logic.
